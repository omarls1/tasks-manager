# 📝 Task Manager

## Overview

Task Manager is a simple and efficient application to manage your daily tasks. It helps you to keep track of your to-do list, set priorities, and ensure that you stay organized.

## Features

- ➕ Add, edit, and delete tasks
- 📌 Set task priorities
- ✅ Mark tasks as completed
- 🔍 Filter tasks by status or priority

## Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/omarls1/tasks-manager
   ```
2. Navigate to the project directory:
   ```sh
   cd task-manager/client
   ```
3. Install dependencies:
   ```sh
   npm install
   ```

## Usage

1. Start the development server:
   ```sh
   npm start
   ```
2. Open your browser and navigate to `http://localhost:3000`.
